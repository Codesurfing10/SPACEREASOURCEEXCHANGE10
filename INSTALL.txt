Remove Thorium from Space Resource Exchange
===========================================
Repo: https://github.com/Codesurfing10/SPACEREASOURCEEXCHANGE

Current main branch seed does NOT include Thorium (LI, He3, PGM, REG, FeNi, SEC, CC only).
If your live DB still has Thorium (older seed or manual add), run:

  cd SPACEREASOURCEEXCHANGE
  source .venv/bin/activate   # if used
  python remove_thorium.py

Or SQL (PostgreSQL / SQLite):

  DELETE FROM payment_preferences WHERE contract_id IN
    (SELECT id FROM contracts WHERE resource_type_id IN
      (SELECT id FROM resource_types WHERE lower(name)='thorium' OR lower(symbol) IN ('th','thor','thorium')));
  DELETE FROM offers WHERE contract_id IN
    (SELECT id FROM contracts WHERE resource_type_id IN
      (SELECT id FROM resource_types WHERE lower(name)='thorium' OR lower(symbol) IN ('th','thor','thorium')));
  DELETE FROM contracts WHERE resource_type_id IN
    (SELECT id FROM resource_types WHERE lower(name)='thorium' OR lower(symbol) IN ('th','thor','thorium'));
  DELETE FROM resource_types WHERE lower(name)='thorium' OR lower(symbol) IN ('th','thor','thorium');
